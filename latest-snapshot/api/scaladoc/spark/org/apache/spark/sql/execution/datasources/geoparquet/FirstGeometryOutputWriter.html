FirstGeometryOutputWriter 

class FirstGeometryOutputWriter extends OutputWriter

Writes a GeoParquet 2 file that has GeometryUDT columns without a CRS option.

GeoParquet 2 states the CRS of a geometry column in the Parquet schema, which the Parquet writer needs before the first row. A GeometryUDT column has an SRID on each geometry only. This writer therefore holds rows back until every such column has shown a geometry, then opens the file with those SRIDs. GeoParquetWriteSupport turns them into the CRS of the columns and rejects a later geometry that has another SRID.

The rows held back are limited to GeoParquetWriteSupport.GEOPARQUET_SRID_LOOKAHEAD_KEY bytes. A column that has shown no geometry by then is written with an unknown CRS.
