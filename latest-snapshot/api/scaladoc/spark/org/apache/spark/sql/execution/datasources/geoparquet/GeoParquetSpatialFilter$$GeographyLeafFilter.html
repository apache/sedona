Companion object GeographyLeafFilter

case class GeographyLeafFilter(columnName: String, west: Double, east: Double, south: Double, north: Double) extends GeoParquetSpatialFilter with Product with Serializable

A predicate between a geography column and a geography of the query that holds for no row whose geography is outside of a box around the geography of the query. Two geographies that intersect have a point in common, and so have one that contains the other and two that are equal, so one box serves these predicates. For a predicate on the distance between the two, the box is larger by that distance.

The geo metadata of a file has no bounding box for a geography column, so no file is skipped by its metadata. A row group is skipped when the bounding box in its geospatial statistics and the box of the query have no point in common.

columnName

name of the filtered geography column

west

western bound of the box of the query in degrees, above east across the antimeridian
